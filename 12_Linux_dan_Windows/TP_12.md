## Dasar Teori
    Ubuntu adalah sistem operasi berbasis Linux yang bersifat open source dan dikembangkan oleh Canonical. Ubuntu banyak digunakan untuk kebutuhan server, pemrograman, jaringan komputer, dan pembelajaran sistem operasi karena terkenal stabil, aman, dan gratis. Ubuntu mendukung sistem multiuser dan multitasking serta memiliki manajemen paket menggunakan APT untuk instalasi software. Selain itu, Ubuntu sering digunakan pada virtual machine seperti Oracle VM VirtualBox.

    Sementara itu, Windows 10 adalah sistem operasi buatan Microsoft yang dirancang untuk komputer desktop maupun laptop dengan tampilan grafis yang mudah digunakan. Windows 10 menjadi salah satu sistem operasi paling populer karena kompatibel dengan banyak aplikasi, driver, dan game. Sistem operasi ini juga mendukung multitasking serta memiliki fitur keamanan seperti Windows Defender.

    Secara umum, kedua sistem operasi memiliki fungsi utama yang sama yaitu mengatur sumber daya komputer, menjalankan aplikasi, dan membantu pengguna dalam berbagai aktivitas. Perbedaannya, Ubuntu lebih banyak digunakan untuk kebutuhan server dan pengembangan sistem, sedangkan Windows 10 lebih umum digunakan untuk kebutuhan sehari-hari dan perkantoran.

## Guided
    1. Virtual machine Ubuntu dijalankan di VirtualBox.
    2. File ISO Ubuntu berhasil booting.
    3. Sistem Ubuntu masuk ke mode live (coba Ubuntu tanpa instalasi penuh).
    4. Karena sistem sudah aktif, Ubuntu menampilkan layar login dengan user bawaan bernama “Live session user”.
