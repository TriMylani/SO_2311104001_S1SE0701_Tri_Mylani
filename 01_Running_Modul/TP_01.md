## Dasar Teori

1. Backend

Backend merupakan mesin virtual yang berfungsi sebagai sistem target tempat kernel atau sistem operasi (seperti Xinu) dijalankan. Backend menerima program atau hasil kompilasi dari development system, kemudian mengeksekusinya dan menampilkan output melalui koneksi serial. Dengan demikian, backend berperan sebagai lingkungan runtime untuk menguji dan menjalankan sistem operasi yang dikembangkan.

2. Development System

Development system adalah mesin virtual yang digunakan sebagai lingkungan pengembangan untuk menulis, mengedit, dan mengompilasi kode program atau kernel. Setelah proses kompilasi selesai, hasil build dikirim ke backend melalui koneksi serial pipe untuk dijalankan. Development system berfungsi sebagai tempat utama bagi programmer untuk melakukan pengembangan, pengujian, dan debugging.

3. Sourcetrail

Sourcetrail adalah alat analisis kode yang digunakan untuk memvisualisasikan struktur dan hubungan antar file, fungsi, serta modul dalam suatu proyek perangkat lunak. Dalam praktikum sistem operasi, Sourcetrail membantu memahami arsitektur kernel dan alur program secara lebih jelas, sehingga memudahkan proses analisis, dokumentasi, dan debugging kode yang kompleks.
