## Dasar Teori
Membaca source code Xinu merupakan proses untuk memahami struktur serta cara kerja sistem operasi Xinu dengan melihat langsung kode program yang digunakan. Kegiatan ini bertujuan agar pengguna dapat mengetahui bagaimana sistem mengelola proses, memori, dan fungsi lainnya secara lebih mendalam. Untuk mempermudah proses tersebut, digunakan aplikasi Sourcetrail yang membantu dalam menelusuri fungsi, file, serta hubungan antar bagian kode secara visual sehingga lebih mudah dipahami.


## Guided
1. Install aplikasi Sourcetrail (jika belum ada).
2. Download source code Xinu dari LMS.
3. Buka aplikasi Sourcetrail.
4. Pilih Project → New Project.
5. Isi nama project (misalnya: xinu) dan tentukan lokasi penyimpanan.
6. Pilih Add Source Groups → C → Empty C Source Group.
7. Pada File & Directories to Index, masukkan folder source code Xinu.
8. Pada Include Paths, isi dengan xinu/include
9. Klik Create untuk membuat project.
10. Setelah itu, lakukan eksplorasi source code Xinu (melihat fungsi, 11. struktur, dan alur program).
